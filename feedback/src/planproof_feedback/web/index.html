Evaluation method, comparability & preservation

Exact counts; numeric quantities within 2%; normalized exact text is a local surrogate. Abstentions and failures count as incorrect completed answers. Scores describe this reference sample, not an official or unseen final benchmark.

Run prompts, tools and image policies may differ. The report pairs source hashes and question IDs; it does not claim identical reasoning conditions. Citation boxes are model proposals: identity and bounds can be checked, semantic support still needs human review.

Original drawings, all questions and reference answers, model requests without authorization headers, raw provider responses, critique stages, settings and hashes remain on disk. Completed benchmark commands also create CRC/SHA256-verified local backups. Existing runs and backups are never pruned.

Adding a saved report here is a local viewing action. Keep its source file or save a comparison snapshot; for permanent registration and backup use the documented benchmark-import command.
