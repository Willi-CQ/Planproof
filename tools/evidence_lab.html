How to read the scores

Wall IoU measures mask overlap (higher is better). Room / object F1 balances precision and recall at IoU ≥ 0.50; rooms use masks and openings/stairs use boxes. TP = matched labels, FP = extra predictions, FN = missed labels. Precision = TP / (TP + FP); recall = TP / (TP + FN). N/A means no supported annotation/model coverage, not zero performance. Source confidence and geometric support scores are not accuracy or comparable probabilities.
