    How to read this comparison
    Direct: clean drawing → Nemotron answer. Guided: frozen ML → deterministic geometry and room proposals → Nemotron routing → up to three registered detail crops → Nemotron answer. Each condition receives a fresh conversation. The original overview pixels, answer prompt, temperature, token limit and thinking setting are matched. The guided condition has additional evidence, context and one routing call; time includes its algorithm work.
    Both answer calls use temperature 0, max_tokens 4096 and enable_thinking=false. The routing stage uses the same model with max_tokens 1024. All attempts remain in the denominator, including abstentions, invalid outputs and transport failures. Reference answers are never sent to Nemotron; scoring follows completion of both conditions. Small-sample results do not demonstrate general accuracy or justify tuning on these cases.
    Citations are checked for identity and bounds, not semantic correctness. Total token counts shown here include all archived responses reporting usage; a timed-out request may have unknown usage. No prices or billed totals are inferred.
